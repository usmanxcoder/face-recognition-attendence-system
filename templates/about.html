Face Recognition Attendance Dashboard

About this project

This local attendance app uses OpenCV face recognition to help record student check-ins, with a Flask dashboard for student and attendance records.

Typical workflow

  1. Add a student and capture face images using the connected camera.
  2. Train the recognition model from the captured images.
  3. Start attendance and review or download the recorded check-ins.
Face images and attendance records are sensitive personal data. Get consent, restrict access, and delete records and images when they are no longer needed. Recognition can be wrong, so provide a manual way to verify attendance.
